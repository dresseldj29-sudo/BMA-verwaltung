# BMA-Verwaltung – Demo-Version

## Demo-Anmeldung
- **Owner:** `owner` / `demo123`
- **Mitarbeiter:** `mitarbeiter` / `demo123`

Die Demo-Anmeldung ist ausdrücklich keine echte Authentifizierung. Daten werden nur im `localStorage` dieses Browsers gespeichert. Andere Geräte und Browser sehen diese Daten nicht; Löschen der Browserdaten kann sie entfernen. Bitte keine vertraulichen oder echten personenbezogenen Daten verwenden.

## Starten
Einfach `index.html` im Browser öffnen. Alternativ kann die Seite über einen statischen Webserver bereitgestellt werden. Bei einem Serverstart mit Node.js: `npm install` und `npm start`.

## Funktionen
BMA-Einträge anlegen, suchen und löschen; Kategorien anlegen/umbenennen; Kostenberechnung; Übersicht und Abmeldung. Die Demo ist für Präsentation und Test gedacht. Server-API, echte Benutzerverwaltung, geräteübergreifende gemeinsame Datenbank, sichere Rollenprüfung, Audit-Protokoll und produktionsreife Owner-Verwaltung sind nicht implementiert.

## Hinweis
Die bisherige Manus-Anmeldung wurde aus der Benutzeroberfläche entfernt. Die Anwendung behauptet nicht, dass die Demo-Anmeldung ein echtes Konto oder eine sichere Sitzung darstellt.
